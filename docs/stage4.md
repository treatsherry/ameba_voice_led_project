# 第四階段：麥克風語音辨識（尚未連動 LED）

雙擊 `Start-LedControl.cmd`，按「辨識一句（麥克風）」，等待「正在聆聽」後說一句話。
辨識文字顯示於語音欄位；操作紀錄另顯示引擎信心分數與收音峰值。
信心分數不是正確率，收音峰值也不代表辨識品質。

本階段診斷版原先只顯示語音、不控制 LED；確認收音片段清楚完整後，下一版改用指定控制語句文法並開始串接 LED。
自動連線查詢只送 STATUS，不改變燈號。

## 實作

- 本機已安裝 `MS-1028-80-DESK`（zh-TW），使用 Windows System.Speech。
- 使用預設麥克風、自由語句 DictationGrammar，未把輸入強制限制成兩句控制詞。
- 程式不呼叫雲端 API，也不上傳錄音。診斷版本會將辨識引擎接受或拒絕的語音片段存成 `build/speech-last.wav`；下一次成功保存時覆寫。介面可播放該片段，匯出的文字紀錄則包含辨識文字。
- 約 7 秒沒有語音會結束；说完停頓後顯示結果。若 8 秒仍未結束，先停止收音並要求處理結果；整體超過約 18 秒才取消。
- 辨識期間顯示即時音量；紀錄增加是否偵測到語音與引擎音訊診斷。
- 可按「取消辨識」，失敗或取消時不沿用先前辨識文字作為本次結果。
- C# 元件 `ui/SpeechCapture.cs` 處理背景辨識事件，UI 定時取得完成結果，避免跨執行緒更新控制項。

## 實測清單

每句分別按一次辨識按鈕：

1. 左邊開燈。
2. 右邊開燈。
3. 今天天氣很好。

記錄「實際說法」與「辨識原文」，確認 LED 狀態未改變。若辨識不準，先檢查預設輸入裝置、麥克風距離及環境噪音，再決定辨識引擎是否適用。
無法收音時，檢查 Windows 的麥克風權限，以及是否允許桌面應用程式使用麥克風。
